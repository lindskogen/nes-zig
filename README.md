# nes-zig


What am I doing? Trying to write an emulator as a first zig project? Let's see how it goes...

## Controls

| Key | Action |
|-----|--------|
| Z | A button |
| X | B button |
| Shift | Select |
| Enter | Start |
| Arrow keys | D-pad |
| 1 | Save state |
| 2 | Load state |
| Esc | Quit |

Save states are written alongside the ROM file (e.g. `roms/game.nes` -> `roms/game.save`).
